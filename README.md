# GreenTech Solutions Website

## Project Description
This project is a multi-page website created for GreenTech Solutions, a company focused on environmental sustainability and technology. The website was designed to introduce the company, explain its mission, highlight its products and services, provide sustainability resources, and give users a way to contact the company. The site is built to support both small to medium-sized businesses and individuals who are interested in eco-friendly technology.

## Features
### HTML
- Multi-page website structure
- Semantic elements such as header, nav, main, section, article, footer, form, table, and lists
- Product, resources, and contact pages
- Local images with descriptive alt text

### CSS
- External stylesheet for all pages
- Green, white, and earthy color palette
- Card-style layout for content sections
- Styled navigation, buttons, forms, tables, and images

### JavaScript
- Newsletter sign-up form response
- Product search and category filter
- Contact form interaction and message display
- High contrast mode toggle for accessibility

### Responsiveness
- Responsive layout using media queries
- Grid and flexible layout adjustments for smaller screens
- Navigation and content stack properly on mobile devices

### Accessibility
- Skip link for keyboard users
- Alt text on all images
- Clear form labels
- High contrast mode option
- Good color contrast and readable layout
- `aria-live` message areas for form responses

## How to Run
